# ETNIKA — сайт и каталог проекта

Единый репозиторий для доработки сайта студии автопортрета ETNIKA с переносом согласованных блоков в Tilda.

- `index.html` — интерактивная HTML-панель задач по блокам сайта.
- `site/index.html` — одна рабочая версия сайта, без бесконечных суффиксов v20/final.
- `data/project.json` — каталог требований, решений, ссылок на фото и конкурентов.
- `data/state.json` — зафиксированные статусы работ.
- `.github/workflows/validate.yml` — автоматическая проверка структуры.

## Порядок работы

1. Обсудить и подтвердить решения внутри карточки нужного блока.
2. Исправить только соответствующую часть `site/index.html` в отдельной ветке.
3. Проверить блок отдельно и в общем сайте, включая мобильную версию и Tilda.
4. Согласовать изменения и слить Pull Request в `main`.
5. Зафиксировать результат в каталоге задач.

Дизайн, фотографии и коммерческие условия из обсуждений **не считать автоматически утверждёнными**. Не публиковать оригинал переписки Telegram, внутренние документы и закрытые файлы.

Публичные ссылки на фотоматериалы также необходимо проверить на допустимость публикации.

## Общие статусы проекта

HTML-панель только отображает состояние из `data/state.json`, которое меняется в GitHub вместе с кодом. Необходимые изменения статусов или исключение задач оформляются через этот проект. Выполненную задачу переводим в «На проверке», затем в «Готово» только после фактического выполнения критериев приёмки.

## Подтверждение задач

Каждая задача имеет один основной раздел и отдельный статус происхождения. **Прямая реплика** подтверждается цитатой; тематический пересказ PDF, HTML v19 и SEO-аудит сами по себе не доказывают согласование. Общие правила не учитываются повторно в задачах каждого блока. Подробности: [аудит задач 28.10.2026](docs/audits/2026-10-28-task-provenance.md).
