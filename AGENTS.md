# ETNIKA — обязательные инструкции для разработки

Перед любой правкой сайта прочитать [docs/design-system.md](docs/design-system.md).

## Типографика — без исключений по инициативе разработчика

- Основной текст всех разделов на десктопе (от 761px): Geologica Thin, вес 100, ровно 18 CSS px, единый токен `--etnika-body-size`, межстрочный интервал 1.55. Мобильные размеры не менять без отдельного согласования (уточнение владельца 24.11.2026). Заголовки и отдельные согласованные роли сохраняются.

- Запрещено уменьшать содержательный текст, подписи, ссылки, кнопки, меню, поля, описания карточек и раскрываемых элементов ниже **16 CSS px**, на экранах от 1920 px — ниже **18 CSS px**.
- Применять `var(--etnika-body-size)` для обычного текста и интерактивных подписей. Не использовать локальные меньшие кегли, мобильные уменьшения, масштабирование или каскадные обходы.
- Если текст не помещается, изменить компоновку, а не размер шрифта.
- Только явно согласованные владельцем исторические декоративные метки и подписи галереи имеют узко ограниченные исключения, описанные в дизайн-системе. Новые исключения запрещены без отдельного согласования.
- Перед завершением проверить фактический размер через getComputedStyle на мобильном, десктопе и большом экране. Не считать работу завершённой при нарушениях.
- Не менять фирменную графику, фотографии или размеры основных заголовков без согласования; заголовки используют общую шкалу дизайн-системы.
- Рабочий сайт — site/index.html, ветка main. Не менять тарифы, пока владелец не согласует их отдельно.

## Публикация и подтверждение результата — обязательное требование владельца 24.11.2026

- После каждого изменения рабочего сайта проверять конкретный deployment текущего коммита в GitHub Pages. Коммит, запуск workflow и статус queued/in_progress не означают публикацию.
- В отчёте явно указывать, опубликован ли нужный коммит; давать ссылку на сайт и подтверждение успешного deployment. Отдельно указывать фактический статус браузерных проверок. Не считать исправление визуально принятым только на основании кода.
- Надпись «СТУДИЯ АВТОПОРТРЕТА» и логотип «ЭТНИКА» в хедере используют одну гарнитуру Forum, вес 400. Не уменьшать надпись ради тесной сетки; адаптировать навигацию.

## Неприкосновенность контента B02 — требование владельца 24.11.2026

- При изменении композиции B02 запрещено сокращать, переписывать, скрывать или удалять исходные заголовки, абзацы, характеристики, показатели, преимущества и их описания. Эталон текстового содержания — коммит 354ec9f43f66bf514ee90d903c074ccb0f869392; восстанавливающая реализация — 9d0e81feedc05d64311fee47c1405e201f47855c. Менять только компоновку и согласованное размещение фотографий. Любые изменения содержания требуют прямого согласования.
- Успешный deploy не доказывает, что CDN отдаёт ожидаемый HTML: после него проверить метку сборки опубликованной страницы и содержимое B02 в реальном браузере, сохранить скриншоты. Не заменять эту проверку успешным локальным тестом.
