# Источники (локальное хранение)

Исходный экспорт Telegram, оригинальные внутренние отчёты и документы с персональными данными **не загружать** в публичный GitHub.

В каталоге опубликованы переработанные требования, задачи и ссылки на визуальные материалы. Указания на страницы относятся к локальному PDF, который хранится отдельно.
