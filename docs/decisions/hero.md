## Что нужно показать для выбора

1. Видеофон с упрощённым текстом и композицией.
2. Статичное fashion-фото из собственного архива.
3. Фотогалерею / смену кадров — только как отдельное предложение.

Все три варианта **не утверждены**. По результатам сравнения принять конкретное решение Анны и Егора.
