## Исправление блока тарифов · 04.11.2026, прямое замечание владельца

Скриншот пользователя от 10:29 зафиксировал явную поломку: три тарифные кнопки обрезаны, описание и заголовок накладываются на список услуг, цена и фотография вынесены в несогласованные слои. Причина: поверх исходной v19 CSS-сетки по ошибке применён промежуточный `pc-main{display:flex}`, но сохранены внутренние сетки с `minmax(0,1fr)` и ограничениями по высоте. 

Для тестового сайта `site/review-2026-11.html` конфликтующий CSS удалён, заменён одним согласованным набором: секция и детали имеют высоту по содержимому, тарифы — устойчивые три карточки сверху, ниже описание с сохранёнными пунктами и фото справа. В мобильном виде тарифы выстроены один под другим, описание и фото тоже последовательно. Все исходные цены и функции переключения будней/выходных сохранены. Старые изображения тарифов заменены на фотографии из папки «Фото для сайта» и «чб» (локально сохранённые в GitHub). Это исправление подтверждено структурной проверкой CSS/HTML; визуальная приёмка пользователя отдельно.
